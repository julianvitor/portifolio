Dark Mode (exemplo)

2023-04-19 • Tailwind/CSS

Em um site estático, você pode implementar tema claro/escuro com um pouco de JavaScript e classes CSS.

Ideia simples

// 1) Alternar uma classe no <html>
document.documentElement.classList.toggle('dark');

No Tailwind, o modo escuro normalmente usa a variante dark:. Aqui estamos usando o Tailwind via CDN, então você pode optar por classes comuns e um CSS pequeno.
