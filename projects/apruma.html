Apruma

Ver no GitHub ↗
C / C++ ESP32 (NodeMCU) MPU-6050 (IMU) WebSockets IoT / Wearable SPIFFS

O Apruma é um wearable biomédico e sistema embarcado inteligente desenvolvido para monitoramento ergonômico e alerta de desvios posturais em tempo real.

Como Funciona

Equipado com o microcontrolador ESP32 e uma unidade de medição inercial (IMU) MPU-6050 conectada via barramento I2C, o dispositivo calcula os ângulos de inclinação (Pitch e Roll) da coluna vertebral em intervalos de alta frequência.

Destaques do Projeto

  • Servidor Web & WebSockets Embarcados: O próprio ESP32 cria um Access Point Wi-Fi e hospeda uma interface web completa (armazenada em memória flash SPIFFS), transmitindo telemetria em tempo real sem latência.
  • Limiares de Postura Parametrizáveis: Análise angular contínua que alerta vibrações ou sinalizadores caso a inclinação ultrapasse os limites biomecânicos recomendados.
  • Integração Hardware-Software: Exemplo prático da união entre eletrônica de precisão, firmware de baixo nível e interface de visualização responsiva.
